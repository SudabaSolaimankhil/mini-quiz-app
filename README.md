# React Quiz App

A simple and responsive quiz application built with **React** and **Vite**.

## Features

* Multiple-choice questions
* Select and change answers
* Previous and Next navigation
* Score calculation
* Quiz restart
* Responsive design

## Technologies

* React
* Vite
* JavaScript
* CSS

## Online Demo

[View the Live Demo](https://sudabasolaimankhil.github.io/mini-quiz-app/)

## Run Locally

```bash
git clone https://github.com/SudabaSolaimankhil/mini-quiz-app.git
cd mini-quiz-app
npm install
npm run dev
```
